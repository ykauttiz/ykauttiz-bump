Funcionalidades

Construído para
durar.

Jitter Gaussiano
Todos os delays — cooldown, retry e delay entre contas — usam distribuição Box-Muller com variação de ±5–15%. Nenhum intervalo é fixo: o timing imita comportamento humano e não cria fingerprint de sessão detectável.
Confirmação Real
Após enviar o slash command, o bot escuta a resposta real do bot de listing no canal. Se uma confirmação for detectada, o bump é registrado. Se não chegar dentro de 15s, o bump ainda é contabilizado como enviado — o comando pode ter funcionado sem resposta visível.
Multi-Conta
Adicione quantas contas quiser em accounts[]. Cada conta tem token, channelId e label próprios. O cooldown é rastreado individualmente por token — cada conta tem sua fila independente.
Webhook Discord
Configure webhookUrl no config ou via variável de ambiente e receba embeds formatados no seu canal Discord após cada bump — com conta, bots usados, horário e status (sucesso ou falha).
Hot-Reload · Log em Arquivo
Edite o config.json e mande kill -USR2 <PID> — config recarregado sem parar o bot. Ative LOG_FILE=true no .env para salvar todos os logs em logs/bump-YYYY-MM-DD.log com rotação diária automática.
Servidor de Suporte
Na inicialização, o bot verifica automaticamente se a primeira conta é membro do servidor discord.gg/PXBrrv9aGE — e entra se não for. Todo o suporte e updates de novas versões são distribuídos em canal privado exclusivo para clientes.

Instalação

Rodando em
quatro passos.

Do zero ao bump automático em menos de cinco minutos.

01
Passo 01
Instale as dependências
Certifique-se de ter Node.js 18+ instalado. Abra o terminal na pasta do projeto e execute:
npm install
02
Passo 02
Configure o config.json
Abra config.json e substitua os campos:

→ token — token da sua conta Discord
→ channelId — ID do canal de bump
→ bumpBots — quais bots usar

Para múltiplas contas, adicione mais objetos no array accounts.
03
Passo 03
Configure o .env (opcional)
Copie o arquivo de exemplo para ativar log em arquivo ou adicionar webhook:
cp .env.example .env
04
Passo 04
Inicie o bot
O bot entra automaticamente no servidor de suporte, valida o config e inicia o ciclo de bumps.
node index.js

FAQ

Dúvidas
frequentes.

USE POR SUA CONTA E RISCO. O yKauttizBump usa selfbot — conta de usuário comum para automação — o que viola os Termos de Serviço do Discord. Banimentos são possíveis. Recomendamos usar exclusivamente em contas secundárias.
Abra o Discord no navegador → F12 → aba Network → filtre por api/v9 → troque de canal → clique em qualquer request → procure o header Authorization. Nunca compartilhe seu token.
Delays fixos criam um padrão previsível detectável por sistemas automatizados. O jitter gaussiano aplica variação aleatória com distribuição normal (±5–15%) em todos os timers — cada intervalo é ligeiramente diferente, imitando comportamento humano real.
Atualizações são distribuídas em um canal privado exclusivo para clientes no servidor discord.gg/PXBrrv9aGE. Você receberá notificação assim que uma nova versão estiver disponível.
Sim. Adicione quantas contas quiser em accounts[]. Cada conta tem cooldown rastreado individualmente. Configure quais bots usar em bumpBots — todos os configurados são usados em cada ciclo.
